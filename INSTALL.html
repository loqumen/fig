Install Fig

Fig is a browser extension paired with a small local companion. Marking up a page and pressing Fig hands the markings to the AI on this machine, which produces the revised page.

Before installing

  1. Claude Code installed and signed in (it does the thinking).
  2. Node.js 18 or later (the companion is a single dependency-free script).

1 — Start the companion

  1. Copy this Fig folder somewhere permanent (Applications or home folder is fine).
  2. In Terminal, run ./companion/install.sh from that folder. It starts the companion and keeps it running at login.

2 — Add the extension

  1. Open chrome://extensions (or brave://extensions), turn on Developer mode, click Load unpacked, and choose this folder's extension directory.
  2. Click the Fig toolbar icon and paste the token from ~/.fig/settings.json (the installer prints where to find it). This gate keeps web pages from driving the companion.
  3. Optional: in the extension's Details, enable Allow access to file URLs so Fig works on local files too.

Use it

  1. Press Option-Shift-F on any page. Draw, drop comment pins, or highlight text with notes.
  2. Press the Fig button. A status page opens and becomes the revised page, with a change log in the corner.
