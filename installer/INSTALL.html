Install Fig

Two steps. There is no token to paste and nothing to run in Terminal.

1 — Install the companion

  1. Drag Fig Companion onto the Applications folder in this window.
  2. Open it once from Applications. It sets itself up, starts running in the background, and keeps running at login. A dialog confirms it is connected.

2 — Add the extension

  1. Open chrome://extensions (or brave://extensions).
  2. Turn on Developer mode, click Load unpacked, and choose the extension folder in this window.

Once Fig is on the Chrome Web Store this step becomes a single Add to Chrome click.

Use it

Press ⌥⇧F on any page. Draw, drop comment pins, or highlight text with notes, then press the Fig button. A status page opens and becomes the revised page, with a change log in the corner.

Click the Fig toolbar icon any time to confirm the companion is connected.

Requires Claude Code, signed in — it does the work. Fig runs on Node, which Claude Code already installs.
Optional: in the extension's Details, enable Allow access to file URLs to use Fig on local files.
